# AI Meeting Summarizer (Nodus)

An AI-powered app that converts meeting audio into:
- Transcript
- TLDR
- Key points
- Action items

## 🚀 Features
- Audio recording/upload
- AI transcription
- Smart summaries
- Export options

## 🛠 Tech Stack
- React / Next.js
- OpenAI (Whisper + GPT)
- Tailwind CSS
